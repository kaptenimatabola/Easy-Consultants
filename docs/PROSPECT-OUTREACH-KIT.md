## Personalization rules
- Use only verified public/company information.
- Mention one concrete observation when available.
- Never invent a pain point.
- Never claim a company has a problem without evidence.
- Keep the first message short.
- Ask for a conversation, not an immediate large commitment.
- Log every contact and response in the CRM.
