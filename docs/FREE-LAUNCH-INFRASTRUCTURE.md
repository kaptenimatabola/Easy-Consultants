## Current public address

- `easy-consultants.netlify.app`
- Netlify project: `easy-consultants`

This is a free platform subdomain, not a purchased custom domain. Netlify documents that every production site can use a `*.netlify.app` address. A custom `.com`, `.co`, `.africa`, or `.ls` domain can be attached later.

## Revenue funnel

Prospect → Website/WhatsApp → Enquiry → Qualification → Discovery → Proposal → Payment → Onboarding → Delivery → Retainer

## Lead capture

The public enquiry form is designed to write into the Supabase `leads` table using the public publishable key. The browser must never receive a Supabase secret/service-role key.

## Commercial rule

Do not wait for a paid domain before selling. The free Netlify address is sufficient for the first acquisition campaign. Upgrade to a custom domain after the business has validated demand or when a professional domain is financially justified.
